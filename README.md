# PrepGen AI - The Intelligent Study Workspace

PrepGen AI is an advanced, full-stack educational application designed to revolutionize how students and professionals generate, consume, and collaborate on study materials. Evolving far beyond a simple note generator, PrepGen AI is a complete "NotebookLM-style" workspace equipped with a personalized AI tutor, spaced repetition (SRS) flashcards, and a simulated community collaboration platform.

Built with a **React (Vite) + TailwindCSS** frontend and a **Node.js + Express + MongoDB** backend, the application utilizes the **Google Gemini API** for its heavy lifting.

---

## 🌟 Key Features

### 1. The Workspace (NotebookLM Style)
- **Split-Pane Architecture:** View your detailed, formatted notes in the center while interacting with study tools on the side.
- **Context-Aware AI Chat:** A persistent, slide-over AI Assistant that understands the exact note you are reading. Ask it questions, request quizzes, or summarize specific sections.
- **Dynamic Document Outliner (TOC):** A beautifully animated, slide-over Table of Contents that parses markdown headings to generate an interactive navigation tree.
- **Mobile-Responsive UI:** The AI Chat and Outliner act as fluid, touch-friendly slide-over drawers on mobile devices, ensuring a seamless experience on any screen size.

### 2. Interactive Study Tools
- **Spaced Repetition System (SRS):** Flashcards generated by the AI automatically enter an SRS algorithm. Flashcards due for review appear on the Home dashboard widget.
- **Review Mode:** A dedicated `/review` page where you can flip cards, mark your confidence level (Forgot, Hard, Good, Easy), and intelligently schedule your next review session to optimize memory retention.
- **Expected Questions:** AI generates simulated Short Answer and Long Answer questions based on the material to test your readiness.

### 3. AI Co-pilot & Deep Interactions
- **Deep Dive Expansion:** Highlight any section of your AI-generated notes and click "Deep Dive" to request a highly detailed, localized expansion of that specific concept.
- **Explain Like I'm 5 (ELI5):** Highlight complex jargon and click the ELI5 floating button to get an instant, simplified analogy from the AI.
- **Audio Playback:** Built-in Text-to-Speech allows you to listen to your notes like a podcast, with play/pause controls.
- **Dynamic Diagrams & Charts:** Integration with Mermaid.js and Recharts allows the AI to render beautiful, interactive flowcharts and graphs directly in your notes.

### 4. User-Authored Manual Notes
- **Create Blank Notes:** Don't want the AI to write it for you? Start from scratch with a blank note using the integrated WYSIWYG Markdown Editor (SimpleMDE).
- **AI Writing Assistant:** While writing your own notes, highlight text and use the AI Co-pilot to **✨ Improve** (fix grammar and tone) or **📝 Summarize** your writing.
- **Turn Manual Notes into Study Tools:** Written your own lecture notes? Click the "Generate Study Tools" button and the AI will read your handwritten content to auto-generate Interactive Flashcards and Expected Questions based on your specific text.

### 5. Community & Collaboration (Simulated UI)
- **Explore Feed:** A Pinterest-style masonry dashboard (`/explore`) that showcases public notes from the community.
- **Note Cloning:** Found a great public note in the Explore feed? Click "Clone" to duplicate it directly into your private Workspace, along with all its flashcards.
- **Share & Permissions Modal:** Inside the Workspace, toggle your note's visibility between `Private` and `Public`. You can also mock-invite peers by email and assign them roles (`Viewer`, `Commenter`, `Editor`).

### 6. Economy & Infrastructure
- **Credits System:** All AI interactions deduct credits (e.g., Note Generation costs credits, Co-pilot costs 5 credits). State is instantly synced across the UI without page reloads.
- **Stripe Integration:** Seamless checkout process to top up AI credits.
- **PDF Export:** Clean, printable PDF generation for offline studying.

## 🛠️ Tech Stack

### Frontend (Client)
- **Framework:** React with Vite
- **Styling:** TailwindCSS (Custom Glassmorphism & Modern UI design)
- **State Management:** Redux Toolkit & LocalStorage
- **Routing:** React Router DOM
- **Rich Text Editor:** React SimpleMDE
- **Animations:** Motion (Framer Motion)
- **Visualizations:** Recharts (Data), Mermaid.js (Diagrams)

### Backend (Server)
- **Framework:** Node.js with Express
- **Database:** MongoDB (using Mongoose)
- **AI Integration:** Google GenAI (`@google/genai` with Gemini models)
- **Payments:** Stripe
- **Authentication:** JWT (JSON Web Tokens) & Firebase Auth (Frontend integration)

## 🚀 Installation & Setup

### Prerequisites
- Node.js (v18+ recommended)
- MongoDB (Local or Atlas URI)
- Stripe Account (for Secret Key and Webhook Secret)
- Google Gemini API Key
- Firebase Project configured for the frontend

### 1. Environment Variables

**Backend (`server/.env`)**
```env
PORT=4000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key
STRIPE_SECRET_KEY=your_stripe_secret_key
STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret
CLIENT_URL=http://localhost:5173
```

**Frontend (`client/.env`)**
```env
VITE_GEMINI_API_KEY=your_google_gemini_api_key
```

*(Note: The frontend `serverURL` is currently configured to `http://localhost:4000` in `client/src/App.jsx`).*

### 2. Install Dependencies
```bash
# Install Server dependencies
cd server
npm install

# Install Client dependencies
cd ../client
npm install
```

### 3. Run the Application
Start both development servers in separate terminal windows:

```bash
# Terminal 1: Start Backend
cd server
npm run dev

# Terminal 2: Start Frontend
cd client
npm run dev
```

The application will be available at `http://localhost:5173`.

### 4. Production Deployment
The frontend is fully optimized for edge delivery and can be seamlessly deployed to **Vercel**. It includes built-in API quota handling (429 Rate Limits) and utilizes high-throughput models like `gemini-3.5-flash-lite` for production stability.
